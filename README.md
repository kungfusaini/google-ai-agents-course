# Google Agents Course

A 5-day course covering Google's Agent Development Kit (ADK) and advanced agent architecture patterns. You can
see the course [here](https://www.kaggle.com/learn-guide/5-day-agents)

Also contains a simple nixenv and direnv setup for environment management

## Course Topics

- **Agent Fundamentals**: Model, tools, and orchestration layers
- **Multi-Agent Systems**: Sequential, parallel, and loop agents
- **Agent Tools & Integration**: Custom tools, MCP, and pausable workflows
- **Context Engineering**: Memory management and session handling
- **Agent Security & Interoperability**: Guardrails and A2A protocols

## Code

Built using **Google Agent Development Kit (ADK)** with Python and Gemini models.
Each day has it's associated code which you can find in the repo.
